# 🎯 红点迷宫模块 (Maze Blind Navigation)

> 核心体验：**真正的盲人摸象** —— 拆弹者完全没有地图信息，只能信任手册的导航指令

---

## 核心机制

### 信息完全不对称

```
┌─────────────────────────────┐     ┌─────────────────────────────┐
│        拆弹者屏幕           │     │      手册持有者屏幕          │
├─────────────────────────────┤     ├─────────────────────────────┤
│                             │     │  迷宫地图 #7                 │
│         ·                   │     │  ┌───┬───┬───┬───┬───┐      │
│                             │     │  │ S │   │ █ │   │   │      │
│    （纯黑背景）              │     │  ├───┼───┼───┼───┼───┤      │
│                             │     │  │   │ █ │ █ │   │   │      │
│              ●              │     │  ├───┼───┼───┼───┼───┤      │
│                             │     │  │   │   │   │ █ │   │      │
│         玩家位置            │     │  ├───┼───┼───┼───┼───┤      │
│         （绿色）            │     │  │ █ │   │   │   │   │      │
│                             │     │  ├───┼───┼───┼───┼───┤      │
│    可以听到撞墙声            │     │  │   │   │ █ │   │ E │      │
│    "咚" = 北墙              │     │  └───┴───┴───┴───┴───┘      │
│    "叮" = 南墙              │     │                             │
│    "嗙" = 东西墙            │     │  S = 起点 (绿色)            │
│                             │     │  E = 终点 (红色)            │
│  [↑]                       │     │  █ = 墙壁                   │
│ [←][↓][→]                  │     │                             │
│                             │     │  当前指令：                  │
│  步数计数器: 0              │     │  "向北走2格，然后向东"       │
└─────────────────────────────┘     └─────────────────────────────┘
```

## 详细设计

### 拆弹者界面

```
┌─────────────────┐
│                 │
│      ●          │  ← 绿色圆点 = 当前位置
│                 │
│                 │
│                 │
│            ·    │  ← 红色圆点 = 出口位置
│                 │     （如果可见范围内）
│                 │
├─────────────────┤
│  [←] [↑] [→]   │  ← 方向键（相对当前朝向）
│      [↓]        │
├─────────────────┤
│  已走: 12步     │
│  撞击: 1次      │
└─────────────────┘
```

**关键设计：没有北南西东，只有"前/后/左/右"**
- 拆弹者初始朝向随机（可能是北/南/东/西）
- 手册持有者必须问："你现在的前是哪个方向？"
- 建立相对坐标系后才能导航

### 手册持有者界面

```
┌────────────────────────────────────┐
│ 迷宫导航手册 #7                     │
├────────────────────────────────────┤
│                                    │
│   起点 ──→ 出口                    │
│   需要的最少步数: 8                │
│                                    │
│   路径提示：                        │
│   1. 从起点向东走1格                │
│   2. 向北走2格                      │
│   3. 向东走1格                      │
│   4. 向南走1格                      │
│   5. 向东走2格                      │
│   6. 向南走1格 → 到达出口           │
│                                    │
├────────────────────────────────────┤
│ 当前状态询问：                       │
│ [你现在的前面是哪个方向？]           │
│ [你左边有墙吗？]                    │
│ [出口在你哪个方向？]                │
└────────────────────────────────────┘
```

## 沟通流程示例

### 第一阶段：建立坐标系
```
拆弹者: "我屏幕上只有一个绿点和一个红点"
手册持有者: "红点在你的哪边？"
拆弹者: "在我的右下方"
手册持有者: "好，现在按'前'键，告诉我你移动了还是没动"
拆弹者: [按前] "没动，听到了'咚'的声音"
手册持有者: "那是撞北墙了。所以你现在是面朝北"
手册持有者: "那你前面是北，后面是南，左是西，右是东"
拆弹者: "明白了"
```

### 第二阶段：导航
```
手册持有者: "向东走1格"
拆弹者: [按右键] "移动了，红点还在右边"
手册持有者: "再向东1格"
拆弹者: [按右键] "咚！撞墙了"
手册持有者: [看地图] "不对，你应该是被其他墙挡住了"
手册持有者: "那你向北走试试"
拆弹者: [按上键] "移动了"
手册持有者: "好，现在向东"
...
```

### 第三阶段：接近出口
```
拆弹者: "红点和绿点重叠了！"
手册持有者: "按确认键！"
拆弹者: [按确认] "解开了！"
```

## 声音反馈系统

| 动作 | 声音 | 说明 |
|------|------|------|
| 撞北墙 | "咚" (低沉) | 北 = 低音 |
| 撞南墙 | "叮" (清脆) | 南 = 高音 |
| 撞东墙 | "嗙" (中音偏右声道) | 东 = 右耳 |
| 撞西墙 | "嘭" (中音偏左声道) | 西 = 左耳 |
| 成功移动 | "沙" (摩擦声) | 脚步声 |
| 接近出口 | 心跳声渐强 | 距离<3格时 |
| 出口可见 | "叮~" | 红点亮起 |

## 迷宫生成规则

### 随机迷宫（5x5 到 8x8）
```
保证：
1. 起点和终点之间至少有一条通路
2. 存在死胡同（错误路径）
3. 最短路径长度 5-15 步
```

### 与序列号联动
```
序列号特征 → 迷宫特性
• 含偶数 → 迷宫有"传送门"（两个同色格子互通）
• 含元音 → 出口位置会缓慢移动（每10秒移1格）
• 末位>5 → 拆弹者能看到自己周围1格的墙壁（微弱轮廓）
```

## 失败条件

| 失败类型 | 触发条件 | 惩罚 |
|---------|---------|------|
| 超时 | 3分钟内未到达出口 | 炸弹时间-30秒 |
| 撞墙过多 | 撞墙10次 | 炸弹时间-15秒 |
| 误入陷阱 | 走进标有"X"的格子 | 立即失误 |
| 方向混乱 | 连续5次按错方向 | 重置迷宫（新布局） |

## 变体设计

### 变体A：动态迷宫
- 每走5步，迷宫墙壁会随机移动1格
- 手册持有者需要实时更新地图

### 变体B：双人迷宫
- 两个拆弹者，各自控制一个绿点
- 需要都到达出口才算成功
- 手册持有者同时指挥两个人

### 变体C：镜像迷宫
- 拆弹者看到的出口位置是镜像的
- 实际出口在对称位置
- 手册持有者需要翻译坐标

## 实现要点

### 技术栈
- 迷宫生成：递归回溯算法
- 声音定位：立体声平衡（左右声道）
- 网络同步：只同步玩家位置，迷宫本地生成（需种子同步）

### UI要点
- 纯黑背景，只有红绿两点
- 移动时有残影效果（方便判断移动方向）
- 可选：添加雷达扫描线效果（营造紧张感）

---

## 为什么这个设计好

1. **极致信息不对称**：拆弹者真的什么都看不到
2. **沟通是唯一的解**：必须说话，无法独自解决
3. **误差累积**：一次方向搞错会导致后续全错
4. **声音辅助**：撞墙声提供额外信息维度
5. **心理恐怖**：在黑屏中摸索的紧张感
