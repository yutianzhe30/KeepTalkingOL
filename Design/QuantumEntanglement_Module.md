# ⚛️ 量子纠缠模块 (Quantum Entanglement)

> 核心体验：**状态观测与连锁反应** —— 拆弹者每次"观测"都会改变系统状态，必须在手册的指导下精确控制观测顺序。

---

## 核心机制

### 信息分割设计

**拆弹者看到：**
```
┌─────────────────────────────┐
│  量子纠缠观测仪             │
│                             │
│   ┌───┐             ┌───┐   │
│   │ A │             │ B │   │
│   │ ? │             │ ? │   │
│   └───┘             └───┘   │
│                             │
│   ┌───┐             ┌───┐   │
│   │ C │             │ D │   │
│   │ ? │             │ ? │   │
│   └───┘             └───┘   │
│                             │
│  [观测] [反转] [锁定状态]     │
└─────────────────────────────┘
```
- 4个量子位（A, B, C, D），初始状态未知（显示 `?`）。
- 每次可以选择一个量子位进行 **[观测]**。
- 观测后，该量子位会坍缩成确定的状态：**[↑] (上旋/红)** 或 **[↓] (下旋/蓝)**。
- 也可以选择 **[反转]** 已知状态的量子位。
- 最终目标是让所有4个量子位达到特定的目标状态，并点击 **[锁定状态]**。

**手册持有者拥有：**
```
量子纠缠定律手册

第一部分：纠缠对判定
首先，询问拆弹者炸弹的序列号特征：
1. 序列号是否有重复字母？
2. 序列号数字之和是奇数还是偶数？

根据以下表格确定纠缠对：
| 条件 | 纠缠对1 | 纠缠对2 | 纠缠关系 |
|---|---|---|---|
| 有重复字母，和为奇数 | A-C | B-D | 同向纠缠 |
| 有重复字母，和为偶数 | A-D | B-C | 反向纠缠 |
| 无重复字母，和为奇数 | A-B | C-D | 同向纠缠 |
| 无重复字母，和为偶数 | A-B | C-D | 反向纠缠 |

*同向纠缠：当一个发生变化（观测坍缩或手动反转）时，另一个也会变为相同状态。
*反向纠缠：当一个发生变化时，另一个会变为相反状态。

第二部分：目标状态
询问拆弹者电池数量：
- 0-2节电池：目标状态为 [↑][↑][↓][↓] (A和B为上，C和D为下)
- 3节以上电池：目标状态为 [↓][↑][↓][↑]
```

---

## 互动与沟通流程

### 难点：观测即改变
拆弹者如果贸然观测，可能会导致已经设好的量子位被联动改变。

**示例沟通：**
```
拆弹者: "有4个量子位A,B,C,D。序列号没有重复字母，数字和是14（偶数）。"
手册持有者: "好的，根据手册，A和B是反向纠缠，C和D是反向纠缠。"
手册持有者: "炸弹上有几节电池？"
拆弹者: "1节。"
手册持有者: "目标状态是 A:[↑] B:[↑] C:[↓] D:[↓]。"
手册持有者: "等等，A和B反向纠缠，不可能同时是[↑]啊！如果A是[↑]，B一定会被变成[↓]！"
```

### 隐藏机制：解除纠缠
当拆弹者连续快速点击两个发生纠缠的量子位（进行"同时观测"），会引发**退相干**，暂时解除它们之间的纠缠关系，持续10秒。

```
手册持有者: "这是一个死局，你必须解除A和B的纠缠。你需要同时观测A和B！"
拆弹者: "怎么同时观测？"
手册持有者: "尝试快速连续点击观测A和B试试看。"
拆弹者: [快速点击A和B] "它们发出滋滋声，纠缠线断开了！"
手册持有者: "快！趁现在把A反转为[↑]，B反转为[↑]！"
```

---

## 惩罚机制

- 错误锁定：如果未达到目标状态点击[锁定状态]，触发失误。
- 观测过载：如果在一个量子位上连续观测/反转超过5次，触发系统过载（失误），并重置所有量子状态为`?`。

---

## 为什么这个设计符合KTANE风格？

1. **强逻辑依赖**：拆弹者完全不知道纠缠关系，盲目操作只会越弄越乱，必须高度依赖手册的逻辑推导。
2. **矛盾重重**：手册持有者会发现"目标状态"与"纠缠定律"之间存在矛盾，迫使他们寻找规则外的解决方案（退相干）。
3. **信息双向校验**："我动了A，B变成了什么？" 需要拆弹者不断反馈操作结果，让手册持有者验证纠缠定律是否判断正确。
