# 🌌 星图对齐模块 (Star Map Alignment)

> 核心体验：**空间导航与模式识别** —— 拆弹者拥有局部视野，手册持有者拥有全局地图，必须通过描述形状来定位。

---

## 核心机制

## 详细设计

### 拆弹者界面

```
┌─────────────────┐
│                 │
│      *          │  ← 视野内只能看到少量的星星
│                 │
│   *      *      │  ← 星星的大小和亮度可能不同
│                 │
│        *        │
│                 │
├─────────────────┤
│ [NW][ N ][NE]   │  ← 8方向导航键
│ [ W ][ ● ][ E ]   │  ← 按下方向键移动视野（平移）
│ [SW][ S ][SE]   │
├─────────────────┤
│  [ 确认扫描 ]    │  ← 当找到目标坐标时点击
└─────────────────┘
```

**关键设计：局部受限视野**
- 拆弹者的屏幕只能看到全地图的大约 1/16 区域。
- 没有坐标显示，不知道自己目前在星图的哪个位置。
- 视野平移是连续的，可以通过按钮微调。

### 手册持有者界面

```
┌────────────────────────────────────┐
│ 天文观测手册                        │
├────────────────────────────────────┤
│                                    │
│ 第一步：定位                        │
│ 询问拆弹者看到的星座形状，在星图上找到对应 │
│ 的位置。                             │
│                                    │
│ 星图特征：                          │
│ [此处是一张复杂的全天星星图，包含几十个星星] │
│                                    │
│ 第二步：寻找目标                      │
│ 根据序列号规则确定目标：               │
│ - 含有元音字母：寻找"猎户座"的腰带中心   │
│ - 含有偶数：寻找"仙后座"的 W 形顶点     │
│ - 否则：寻找"大熊座"的勺子把手尖端      │
│                                    │
│ 第三步：导航                        │
│ 告诉拆弹者如何从当前位置移动到目标位置。  │
│ （例如："向东北方向移动2次，再向东移动1次"） │
└────────────────────────────────────┘
```

## 沟通流程示例

### 第一阶段：定位
```
拆弹者: "我看到四颗星，组成一个很长的菱形，最下面那颗最亮。"
手册持有者: [查阅星图] "那应该是南十字座。它旁边是不是有一颗单独的很暗的星？"
拆弹者: [向右微调视野] "对，在它的东方有一颗暗星。"
手册持有者: "好，我确定你的位置了，你在星图的左下角。"
```

### 第二阶段：计算目标
```
手册持有者: "等一下，我看看序列号... 有元音字母吗？"
拆弹者: "有，序列号是 E3K9Q1。"
手册持有者: "好的，我们的目标是'猎户座'的腰带中心。那是在星图的右上部分。"
```

### 第三阶段：导航
```
手册持有者: "从你现在的位置，一直向东北方向（NE）移动，大约按4次。"
拆弹者: [按 NE 4次] "移动了。我现在看到三颗连成一线的星星，很亮。"
手册持有者: "那就是猎户座的腰带！把视野中心对准那三颗星的中间那颗。"
拆弹者: "对准了。"
手册持有者: "按下'确认扫描'。"
拆弹者: [按下] "绿灯亮了！模块解除！"
```

## 失败条件

| 失败类型 | 触发条件 | 惩罚 |
|---------|---------|------|
| 扫描错误 | 视野中心不在目标星星上时按下"确认扫描" | 炸弹时间-30秒，失误次数+1 |
| 偏离星图 | 试图向星图边界外移动过多 | 视野会"重置"到一个新的随机位置，需要重新定位 |

## 变体与干扰机制

### 宇宙尘埃（视觉干扰）
- 偶尔会有星云或尘埃飘过拆弹者的视野，遮挡部分星星。
- 手册持有者需要告诉拆弹者等待尘埃散去。

### 坐标系旋转
- 拆弹者的"上"可能不是星图的"北"。
- 手册持有者需要通过星星的相对位置来判断拆弹者视野的旋转角度（例如："菱形是竖着的还是横着的？"）。

### 流星雨（时间压力）
- 如果太久不操作，会有流星划过。虽然没有直接伤害，但会扰乱视线，并伴随警报声增加紧张感。

---

## 为什么这个设计好？

1. **强烈的空间方位感沟通**：不仅要描述形状，还要描述相对位置（上、下、左、右）。
2. **渐进的解题过程**：定位 -> 寻的 -> 微调，步骤清晰但需要紧密配合。
3. **视觉驱动**：非常符合人类对于"观星"的浪漫和探索感，同时转化为沟通的挑战。
4. **易于扩展**：可以通过增加星星数量、改变星座形状、引入旋转来轻松调节难度。
