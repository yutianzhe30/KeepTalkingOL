## 新模块提案

### 1. 🔊 摩斯电码模块 (Morse Code)

#### 视觉设计
```
┌─────────────────┐
│  🔴 [LED]        │  <- 闪烁区域
│                 │
│  ┌───┐ ┌───┐   │
│  │ 3 │ │ 5 │   │  <- 两个频率拨盘 (0-9)
│  └───┘ └───┘   │
│  ┌─────────┐   │
│  │  发送   │   │  <- 确认按钮
│  └─────────┘   │
└─────────────────┘
```

#### 核心玩法
- LED 以摩斯电码闪烁一个字母（如 `···−` = V）
- 玩家查阅说明书中的**频率对照表**
- 旋转两个拨盘输入对应频率数字
- 点击发送确认

#### 频率对照表示例
| 字母 | 摩斯 | 频率 |
|------|------|------|
| A | `·−` | 35 |
| B | `−···` | 12 |
| V | `···−` | 58 |

#### 与序列号联动
- **序列号含元音字母(A,E,I,O,U)**：使用左侧频率表
- **否则**：使用右侧频率表（数字偏移+10）

#### 失败条件
- 输入错误频率 → 触发失误
- 超时未输入 → 自动触发失误

### 2. 🎨 调色盘模块 (Color Mix)

#### 视觉设计
```
┌─────────────────┐
│  目标: [🟧]      │  <- 目标颜色
│                 │
│  当前: [⬜]      │  <- 当前混合色
│                 │
│  R [━━━●━━]     │  <- 红 滑块 0-255
│  G [━●━━━━]     │  <- 绿 滑块 0-255
│  B [━━━━●━]     │  <- 蓝 滑块 0-255
│                 │
│  [  确认  ]      │
└─────────────────┘
```

#### 核心玩法
- 显示一个目标颜色（如橙色 `#FF8800`）
- 玩家通过三个滑块调节 RGB 值
- 当当前颜色与目标颜色**色差 < 30** 时，确认按钮可用

#### 难度递进
| 难度 | 目标颜色特征 |
|------|-------------|
| 简单 | 纯红/绿/蓝/黄/紫/青 |
| 中等 | 需要混合（如粉红、橄榄绿） |
| 困难 | 接近色（深红 vs 暗红） |

#### 与序列号联动
- **序列号末位为奇数**：目标颜色偏暖色调
- **末位为偶数**：目标颜色偏冷色调

### 3. 🧩 记忆序列模块 (Memory)

#### 视觉设计
```
┌─────────────────┐
│  阶段: 3/5       │  <- 进度指示
│                 │
│  ┌───┐ ┌───┐   │
│  │ 1 │ │ 2 │   │  <- 4个方形按钮
│  └───┘ └───┘   │     带数字标签
│  ┌───┐ ┌───┐   │
│  │ 3 │ │ 4 │   │
│  └───┘ └───┘   │
│                 │
│  [开始演示]      │  <- 开始按钮
└─────────────────┘
```

#### 核心玩法
- 点击开始后，按钮按特定顺序闪烁
- 玩家需要按相同顺序点击
- 共 5 个阶段，每阶段增加一个步骤
- 全部完成即解锁

#### 规则变化（增加复杂度）
每一阶段的规则可能变化：
- **阶段1-2**：直接重复看到的顺序
- **阶段3-4**：倒序点击
- **阶段5**：点击看到的数字 +1（1→2, 4→1循环）

#### 与序列号联动
- **序列号第3位数字**：决定起始阶段（如3则从阶段3开始）
- **序列号含数字7**：规则反转（阶段1倒序，阶段3正序）

### 4. 🌀 迷宫追踪模块 (Maze Chase)

#### 视觉设计
```
┌─────────────────┐
│  ┌───────────┐  │
│  │ ▓▓▓▓▓▓▓▓▓ │  │  <- 5x5 网格迷宫
│  │ ▓ ○   ▓ █ │  │     ○ = 玩家光点
│  │ ▓ ▓▓▓ ▓ ▓ │  │     █ = 终点
│  │ ▓   ▓   ▓ │  │     ▓ = 墙壁
│  │ ▓▓▓   ▓▓▓ │  │
│  └───────────┘  │
│                 │
│  [←][↑][↓][→]  │  <- 方向键
└─────────────────┘
```

#### 核心玩法
- 5x5 网格迷宫，玩家控制光点移动
- 需要在**限时内**到达终点
- 迷宫墙壁会**周期性闪烁**（显示/隐藏）

#### 动态机制
- 每 3 秒，墙壁会隐藏 1 秒，然后显示新布局
- 玩家需要记忆路径，在隐藏期间盲走

#### 与序列号联动
- **序列号前两位数字之和**：决定初始迷宫复杂度（3-18）
- **序列号含字母**：墙壁闪烁周期延长（简单模式）

### 5. 💨 压力阀门模块 (Pressure Valves)

#### 视觉设计
```
┌─────────────────┐
│  总压: 100%      │
│                 │
│  [━━━━━━━] 80%  │  <- 阀门A (太高)
│  [━━━]     30%  │  <- 阀门B (太低)
│  [━━━━]    45%  │  <- 阀门C (目标)
│  [━━━━━━]  70%  │  <- 阀门D (太高)
│                 │
│  [  平衡  ]      │  <- 确认按钮
└─────────────────┘
```

#### 核心玩法
- 4 个阀门，初始压力随机
- 点击阀门可增加/减少压力（循环：0% → 25% → 50% → 75% → 100% → 0%）
- 目标是让所有阀门压力**都在 40%-60% 范围内**

#### 连锁反应
- 调节一个阀门会影响相邻阀门的压力 ±10%
- 需要找到平衡状态

#### 与序列号联动
- **序列号数字之和**：决定目标压力范围偏移
  - 和 < 15：目标 30%-50%
  - 和 ≥ 15：目标 50%-70%

### 6. 🔢 数学密码模块 (Math Cipher)

#### 视觉设计
```
┌─────────────────┐
│  2 + □ = 7      │  <- 算式（有1个未知数）
│  □ × 3 = 12     │
│  15 − □ = 9     │
│  □ ÷ 2 = 4      │
│                 │
│  [5] [4] [6]    │  <- 数字键盘
│  [3] [2] [8]    │
│  [1] [7] [9]    │
│  [    0    ]    │
└─────────────────┘
```

#### 核心玩法
- 显示 4 道简单数学题，每道有 1 个未知数
- 解出 4 个答案，按顺序输入（如 5,4,6,8 → 输入 5468）
- 限时 60 秒完成

#### 干扰机制
- 每 15 秒，一道题的运算符会**随机变化**（+变-，×变÷）
- 玩家需要快速完成或重新计算

#### 与序列号联动
- **序列号末位**：决定哪道题的运算符不会变化（如4则第4题稳定）

## 模块组合建议

### 简单模式（教程）推荐组合
| 槽位 | 模块 | 说明 |
|------|------|------|
| 1 | 序列号 | 提供线索 |

```
├────────┼────────┼────────┼────────┤

└────────┴────────┴────────┴────────┘
```

## 实现优先级

| 优先级 | 模块 | 理由 |
|--------|------|------|
| 🔴 高 | 摩斯电码 | 与现有风格契合，有信息查阅乐趣 |
| 🔴 高 | 记忆序列 | 经典机制，实现简单 |
| 🟡 中 | 压力阀门 | 有连锁反应深度 |
| 🟡 中 | 调色盘 | 视觉效果佳，但色盲需考虑 |
| 🟢 低 | 迷宫追踪 | 需要更多UI空间 |
| 🟢 低 | 数学密码 | 可能有玩家排斥数学 |
