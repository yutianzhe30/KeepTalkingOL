# 🎮 新模块设计提案 - 空间与动态交互模块

> 文档状态：设计草案
> 游戏模式：双人异步合作（拆弹者 + 手册持有者）
> 核心挑战：**无网格空间描述**与**动态反馈控制**

---

## 模块提案 1: ✨ 星象仪模块 (Stargazer)

> 核心机制：**无参照物空间几何描述**

### 设计意图
挑战玩家描述**相对位置**和**几何形状**的能力。没有网格线，没有东南西北，只有大小不一的光点和相对距离。

### 信息分割设计

**拆弹者看到：**
```
┌─────────────────────────────┐
│                             │
│       ★ (蓝)                │
│                 · (白)      │
│                             │
│     * (红)                  │
│             ★ (红)          │
│                             │
│                   * (黄)    │
│                             │
│  [ 连接星星 ] [ 验证星座 ]  │
└─────────────────────────────┘
```
- 一片漆黑的星空，随机散布 5-7 颗不同颜色和大小的星星。
- **没有网格，没有坐标系**。
- 拆弹者可以通过点击星星在它们之间画线。
- **操作不可见性**：画出的线是半透明的，且连错不会立即报错。只有点击【验证星座】时才会判定。

**手册持有者拥有：**
```
《星象观测指南》

第一部分：定位基准星
1. 找出最亮的红色星星（大红星）。
2. 找出离它最远的蓝色星星。
3. 这两颗星的连线定义为"基准轴"。

第二部分：构建星座（根据序列号规则）
规则 A（序列号含奇数）：
  - 从大红星开始，连接距离它最近的白色星星。
  - 再从白星连接到蓝星。
  - 最后将蓝星连接到黄星，形成一个"勺子"或"折线"状。

规则 B（序列号全偶数）：
  - 以基准轴为对角线，寻找能与基准轴构成面积最大的三角形的第三颗星。
  - 连接这三颗星形成闭合三角形。
  - 忽略所有黄色星星。
```

### 沟通挑战
- **缺乏绝对坐标**："左上角"、"右下角"这种描述极易出错，因为星空可能是旋转过的（或者根本没有明确的边界感）。
- **相对距离判断**："离它最近的白星"可能肉眼看起来两颗白星距离差不多，需要仔细确认。
- **形状描述**："它看起来像个钝角三角形" 或者 "它们连起来像个倒着的Y"。

### 沟通流程示例
```
拆弹者: "有5颗星。一个大红的，一个小红的。一个大的蓝的，一个小白的，一个小黄的。"
手册持有者: "大红星和蓝星离得远吗？"
拆弹者: "很远，大红星在左边偏下，蓝星在右上角。"
手册持有者: "好，把它们俩在脑海里连一条线，当作基准线。"
手册持有者: "序列号有个奇数3，我们用规则A。先点大红星，然后找离它最近的白星，点它。"
拆弹者: "白星在大红星和蓝星中间偏上一点的位置。连好了。"
手册持有者: "然后从白星连到蓝星。"
拆弹者: "连好了。现在是一个折线。"
手册持有者: "最后把蓝星连到黄星。黄星在哪？"
拆弹者: "黄星在右下角。连好了，像个不规则的闪电形状。"
手册持有者: "听起来对，按验证！"
```

## 模块提案 2: 🧪 化学反应釜 (Chemical Reactor)

> 核心机制：**高压动态反馈**与**实时指令变更**

### 设计意图
打破静态的回合制沟通。模块状态在实时剧烈变化，拆弹者必须不断报告新状态，手册持有者必须快速在多个规则表中穿梭并下达**时效性极强的指令**。

### 信息分割设计

**拆弹者看到：**
```
┌─────────────────────────────┐
│ 反应温度: [==========] 85°C │  ← 进度条快速波动上升
│ 溶液颜色: 🟪 紫色           │  ← 颜色会突变
│                             │
│ [ 注入冷凝剂 ] [ 加入催化剂 ]│
│ [ 开启排气阀 ] [ 紧急搅拌 ]  │  ← 4个操作按钮，按下后会有数秒CD
│                             │
│ 阶段: 1/3      稳定度: 70%  │  ← 稳定度归零即爆炸
└─────────────────────────────┘
```
- **温度条**一直在快速上升或下降，极不稳定。
- **溶液颜色**（紫、绿、橙、蓝）会随着温度和操作突然改变。
- 玩家按下按钮后，状态会发生剧烈变化，且按钮有冷却时间。
- 目标：让反应堆在3个阶段中都存活（例如每次保持稳定达到20秒进入下一阶段）。

**手册持有者拥有：**
```
《危险化学品处置手册》

警告：绝对不要在橙色溶液且温度超过80度时开启排气阀！

基础应对法则：
【当温度 > 80°C 时】
 - 如果溶液是紫色：立即【注入冷凝剂】
 - 如果溶液是绿色：立即【紧急搅拌】
 - 如果溶液是蓝色：必须先【加入催化剂】，等待温度下降到60°C以下，再【开启排气阀】

【当温度 < 30°C 时】
 - 如果溶液是橙色：立即【加入催化剂】
 - 如果溶液是蓝色：立即关闭所有阀门（什么都不做，警告拆弹者别按！）

突发事件（必须在3秒内响应）：
 - 如果温度条变成红色闪烁且发出警报：无视所有颜色规则，必须立即【开启排气阀】，否则稳定度将暴跌！
```

### 沟通挑战
- **指令的时效性**：当手册持有者刚查完规则说"按冷凝剂"时，颜色可能已经变了，导致按错。
- **打断与重置**：拆弹者需要不停地报状态，手册持有者需要随时打断自己正在看的规则。
- **高频信息过载**：需要建立非常精简的暗号或缩写来沟通（例如："紫80！" -> "冷凝！"）。

### 沟通流程示例
```
拆弹者: "紫色，50度，温度在升。"
手册持有者: "紫50安全。等超过80告诉我。"
拆弹者: "60，70，75，变绿色了！"
手册持有者: "绿色！超过80立刻搅拌！"
拆弹者: "82了！按了搅拌！温度降了...掉到40了。变橙色了！还在掉！"
手册持有者: "橙色！跌破30加催化剂！绝对不能按排气！"
拆弹者: "25度了！按催化剂！"
拆弹者: "[警报声] 温度条闪红了！！"
手册持有者: "排气！立刻排气！无视颜色！"
```

## 模块对比

| 模块 | 沟通能力偏向 | 节奏感 | 容错率 | 推荐位置 |
|------|-------------|-------|--------|----------|
| **星象仪** | 空间想象、精准描述、耐心 | 缓慢、静态 | 低（验证定生死） | 游戏中期，考验配合默契 |
| **化学反应釜** | 快速反应、信息提炼、抗压 | 极快、动态 | 中（稳定度缓冲） | 游戏后期，制造混乱和压力高潮 |
